Course Contents & Lec/Lab

Key Topics

  • Data collection, logging, and source instrumentation
  • Data validation and data augmentation
  • Dataset labeling, annotator agreement, and active learning
  • Hyperparameter search and AutoML frameworks
  • Model checkpointing and experiment tracking
  • Data version management
  • Docker containerization and cloud infrastructure (AWS/GCP/Azure)
  • Run-time profiling and memory footprint management
  • GPU utilization tracking and optimization
  • Production A/B testing and model redeployment
  • Covariate shift management and automated retraining
  • Model quantization and edge device deployment (TF-Lite)
